# 拾序 Studio — 單檔離線看板

本目錄為網頁版；Windows 桌面版位於隔壁的 `../desktop`。兩者可透過 JSON 備份搬移資料。

## 立即使用

1. 將 `index.html` 放在固定的資料夾。
2. 雙擊 `index.html`，以一般模式的 Chrome 或 Edge 開啟。
3. 畫面右上角顯示「已儲存在本機」，即代表目前完整資料已成功寫入瀏覽器。
4. 下次用**相同瀏覽器、相同使用者設定檔、相同檔案路徑**開啟，程式會讀取上次儲存的狀態。

不需 Node.js、不需安裝套件、不需啟動伺服器、不需網路。HTML 已包含所有 CSS、JavaScript、SVG 圖示與封面視覺。首次開啟附有可自行編輯的示範卡片；後續啟動不會以示範資料覆蓋有效的既有資料。

## 操作方式

### 版面與導覽

- 側欄 **WORKSPACE** 有「我的看板」與「隨手便簽」兩個工作區；**YOUR TOOLS** 有時間工具箱、管理標籤與資料與備份。
- 側欄「外觀主題」可切換「經典」與「大肥魚」，偏好會在同一瀏覽器與 HTML 路徑重開時保留。
- 頂列中央可搜尋目前的看板或便簽。右側圖示可在卡片看板與便簽看板之間切換，日期顯示在圖示後方。
- 卡片看板上方以頁籤切換「全部卡片／已收藏／七天內到期」，頁籤上顯示各自數量；可用滑鼠點選，或聚焦頁籤後以方向鍵、Home、End 切換。
- 側欄底部顯示電腦本地時間的時鐘（時:分:秒）與完整日期；頁面隱藏時暫停更新，回到畫面立即校正。
- 看板、便簽與時間工具共用精簡的標題區：一列放標題、頁籤與操作按鈕，下方一列小字顯示數量與標籤篩選，讓內容區保留更多高度。

### 便簽看板

由側欄 WORKSPACE 的「隨手便簽」或頂列便簽圖示切換至完整的便簽看板。按「新增便簽」後，在輸入視窗填寫多行文字、選擇顏色，按「完成」才建立便簽；取消不會建立空白便簽。

- 拖曳便簽上緣自由移動，拖曳右下角斜線把手調整寬高。
- 點內容或鉛筆按鈕，開啟編輯視窗；完成後套用文字與顏色，取消保留原內容。
- 釘選為「置頂」標記，**不鎖住拖曳或調整大小**；有清楚的置頂徽章。
- 聚焦上緣後可用方向鍵移動；聚焦右下角後可用方向鍵調整大小，Shift 加速。拖曳或縮放中按 Esc 取消。
- 刪除先確認，可取消，刪除後可由提示復原。頂列搜尋會在便簽看板內搜尋便簽全文。

每張最多 10,000 字元，共 100 張。按完成、移動結束或縮放結束後儲存，重開後保留全文、顏色、位置、尺寸及置頂狀態。寬度範圍為 220～900px、高度 180～1,000px；工作區可上下左右捲動，因此換到小螢幕不會自動改寫原尺寸與位置。

「回到看板」或側欄看板入口可切回卡片看板，兩個畫面共用一份資料與 JSON 備份。還原舊備份會清空目前便簽，請先匯出目前資料；確認視窗會提示，並提供還原後的復原。既有便簽未保存尺寸時自動沿用原本的 260×246px，不會刪除內容。新版資料 schema 為 2，可讀入舊 schema 1；正式桌面版 1.1.0 支援新版格式。

### 時間工具箱

側欄「時間工具箱」以四個頁籤分別顯示鬧鐘、番茄鐘、倒數計時與碼表，一次只顯示一個工具。待確認提醒與音效設定固定在右側（窄螢幕在下方），切換任何頁籤都看得到。切換頁籤不會停止計時；進行中的工具會在頁籤旁顯示綠點。按提醒橫幅的「查看提醒」會切到該提醒所屬的工具頁籤。

| 工具 | 操作 |
| --- | --- |
| 鬧鐘 | 輸入名稱與未來的日期時間，新增後可編輯、停用／啟用或刪除；每個提醒一次，最多 50 個。 |
| 番茄鐘 | 專注 1～180 分鐘、休息 1～60 分鐘，設定 1～12 輪；可自動接續或等待手動繼續。最後一輪專注結束即完成。 |
| 倒數計時 | 設定 1 秒～24 小時，開始／暫停／繼續；重設後可修改設定。 |
| 碼表 | 開始／暫停／繼續，按「計次」記錄分段與累計；最多 100 次，累計上限 7 天。 |

有效的閒置時長設定會在變更時自動儲存，進行中及暫停時保留設定；重設會先確認。切換看板或便簽不會停止計時，重開會依保存的時間戳接續，延遲更新也不會以逐秒遞減的方式累積誤差。

建議先按「試聽提醒音」，確認瀏覽器已允許音效及實際音量。提醒音可關閉；視覺提醒會在所有畫面頂部顯示，工具箱內最多保留 20 則待確認提醒。

**頁面或程式完全關閉時不會在背景響鈴。** 背景分頁或休眠可能延後提醒，回到畫面／重開時會補算。此功能沒有建立系統鬧鐘或常駐服務。

時間工具隨 JSON 備份保存；匯入時會還原設定、重設倒數與番茄鐘、暫停碼表、停用過期鬧鐘，待確認提醒不匯入。確認視窗會說明這些行為，並提供還原後的復原。

### 看板操作

| 操作 | 方法 |
| --- | --- |
| 修改看板名稱 | 直接點上方的看板名稱輸入 |
| 新增卡片 | 右上「新增卡片」，或列表下方「新增卡片」；Enter 送出，Shift+Enter 換行 |
| 新增列表 | 橫向捲至最右，點「新增一個列表」 |
| 卡片排序／跨列搬移 | 按住卡片拖動；靠近畫布左右邊緣或卡片區上下邊緣會自動捲動 |
| 列表排序 | 按住列表標題區左右拖動；也可由列表選單使用「往左／右移動」 |
| 取消拖拽 | 按 Esc；視窗失去焦點或指標操作取消時也會取消拖拽 |
| 編輯卡片 | 點卡片；鍵盤聚焦卡片時可按 Enter 或空白鍵 |
| 子任務 | 卡片視窗內新增、編輯名稱、勾選或刪除。拖曳步驟左側的把手，或聚焦把手後按上下方向鍵，即可調整順序 |
| 多色標籤 | 在卡片視窗中點選標籤，可複選；側欄「管理標籤」可修改六種標籤名稱 |
| 封面／到期日 | 在卡片視窗中選擇星軌、山丘、日出或無封面，並設定到期日 |
| 移動卡片的另一種方式 | 在卡片視窗「移動至列表」選擇目標，卡片會加入該列表末端 |
| 收藏與搜尋 | 卡片星號可收藏；看板上方頁籤切換「全部卡片／已收藏／七天內到期」；搜尋支援標題、描述、子任務及標籤名稱 |
| 標籤篩選 | 點看板右上彩色圓點，再點一次取消；「清除篩選」重設所有條件 |
| 複製／刪除卡片 | 在卡片視窗底部操作；刪除後可點提示中的「復原」 |
| 刪除列表 | 列表右上「⋯」選單；確認後刪除整列與內含卡片，可在提示中復原 |
| 備份／還原 | 側欄「資料與備份」匯出 JSON 或選擇先前的 JSON 備份 |

卡片標題、描述、子任務文字等每次輸入都會同步寫入；不必按「儲存」。新增卡片／列表會在送出時儲存；拖拽會在放開指標、確定新順序時儲存。復原提示會保留到你關閉它或出現下一則操作提示，請在需要時及時使用。

點擊對話框外會保留視窗。可按視窗內的關閉或取消按鈕，也可按 `Esc` 關閉。拖曳步驟途中按 `Esc` 會先取消拖曳，保留卡片視窗。

快捷鍵：`N` 新增卡片；`Ctrl+K` 搜尋；`Esc` 關閉卡片、取消拖拽或收起選單。輸入文字時不觸發 `N` 快捷鍵。小螢幕可由左上角選單開啟側欄；看板維持橫向捲動。系統啟用「減少動態效果」時，會自動略過縮放與讓位動畫。

## 資料如何保留

- 使用 `localStorage`，主資料鍵為 `shixu.studio.board.v1`。
- 以單一 JSON 儲存完整狀態：看板名稱、列表順序、卡片順序、標籤名稱／選取、子任務及勾選、收藏、描述、封面與到期日。
- 每次成功寫入主資料後，嘗試將上一份有效狀態存入 `shixu.studio.board.v1.previous`。這份備援同樣存在瀏覽器，不能取代匯出的 JSON 備份。
- 啟動時驗證資料結構與識別碼。若主資料損壞，會嘗試還原上一份有效狀態，並顯示提示、暫停自動覆寫，讓你先匯出。這種復原最多只能找回上一份有效快照。
- 若儲存被禁止、空間不足或發生錯誤，會顯示「尚未儲存」及常駐提示；此時新變更只在記憶體，應立即匯出，勿直接關閉。
- 偵測到其他視窗更動資料時，會暫停此視窗儲存，讓你先匯出需要保留的內容，再確認載入最新版本。此機制降低一般多視窗覆寫風險；localStorage 並非交易式多人協作資料庫，請盡量只使用一個編輯視窗。
- 匯入前檢查版本、欄位、日期、巢狀子任務與重複 ID；不合格式不會覆蓋目前資料。確認還原後會立即儲存，並提供一次復原。
- 目前支援最多 150 個列表、10,000 張卡片、每張 1,000 個子任務，匯入檔案上限 20 MB；實際儲存量仍受瀏覽器配額限制。

**使用範圍與備份：** 在允許儲存的一般瀏覽器模式中，localStorage 可跨關閉瀏覽器與重新開機保留。但直接開啟 `file://` 檔案時，各瀏覽器的儲存行為沒有統一保證；無痕模式、清除網站資料、瀏覽器政策、切換設定檔、移動或更名 HTML 都可能使資料不可用。請固定開啟位置並定期匯出。這是單檔 HTML 的瀏覽器儲存邊界，不能保證資料在清除瀏覽器資料後仍存在。參考：[MDN localStorage 說明](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)。

**搬到其他電腦或資料夾：** 先「資料與備份 → 下載備份」，確認 JSON 已下載；複製 HTML 與 JSON 至新位置，開啟 HTML，再匯入 JSON。只複製 HTML 不會帶走瀏覽器內的資料。備份包含所有卡片內容，請自行保管。

建議首次正式使用前，建立一張測試卡片、勾選一個子任務、確認「已儲存在本機」，關閉後從相同位置再次開啟，確認你目前的瀏覽器設定允許保存，再放入重要資料。

## 程式結構與開發驗證

交付檔案：

- `index.html`：完整可執行程式，也是唯一需要帶走的執行檔案。**由 `src/` 組裝產生，請勿直接修改。**
- `README.md`：操作方式與儲存說明。
- `build.cjs`：把 `src/` 組裝成單檔 `index.html`。
- `verify.cjs`：開發用驗證程式，使用者不需要執行或安裝 Node.js。

### 原始碼結構（`src/`）

為了維護，原始碼拆成多個檔案；交付時仍組裝成一個可雙擊開啟、無外部資源的 `index.html`。

```text
src/
├─ index.html          外殼範本：決定樣式、片段與程式的組裝順序
├─ styles/
│  ├─ base.css         基礎樣式、側欄、卡片、列表、對話框、拖拽
│  ├─ notes.css        便簽看板
│  ├─ time.css         時間工具箱（頁籤面板與右側提醒欄）
│  ├─ readability.css  字級、行高與對比
│  ├─ header.css       精簡標題區與頁籤（看板、便簽、時間工具共用）
│  └─ appearance.css  主題配色與背景
├─ assets/             組裝時內嵌的 WebP 主題素材
├─ partials/           HTML 片段：icons、sidebar、topbar、kanban、notes、time、footer、dialogs
└─ scripts/            依序串接、共用同一個 IIFE 作用域
   ├─ core.js          常數、資料驗證、載入與儲存
   ├─ tabs.js          共用頁籤（選取狀態與方向鍵）
   ├─ notes.js         便簽
   ├─ time.js          時間工具
   ├─ board.js         看板繪製與數量統計
   ├─ ui.js            提示、側欄、新增卡片／列表、選單、確認視窗
   ├─ card-editor.js   卡片視窗與子任務
   ├─ todo-order.js    子任務拖曳與鍵盤排序
   ├─ data.js          匯出、匯入與多視窗衝突
   ├─ shortcuts.js     快捷鍵
   ├─ drag.js          卡片與列表拖拽
   ├─ clock.js         側欄時鐘
   ├─ appearance.js    主題切換與本機偏好
   └─ boot.js          啟動
```

範本或片段中整行的 `<!-- @include 路徑 -->`（HTML）或 `/* @include 路徑 */`（CSS／JS）會被換成該檔案內容。JS 片段沒有模組系統，彼此直接共用變數與函式，因此**片段順序有意義**：被頂層程式碼立即呼叫的函式與 `const` 必須在前面的片段宣告。新增檔案時，記得在 `src/index.html` 加上 include。

修改後執行：

```text
node build.cjs          產生 index.html
node build.cjs --check  只檢查 index.html 是否與 src 一致
node verify.cjs         邏輯驗證；index.html 過期時會直接失敗
```

桌面版的 `npm run prepare:app`（以及 `npm start`／`npm test`／發布）會先自動組裝 `index.html`。

組裝後的 `<style>` 為完整介面樣式；最後的 `<script>` 包含資料驗證、同步儲存、卡片編輯、搜尋、備份和 Pointer Events 拖拽。拖拽使用佔位元素、FLIP／Web Animations API 讓位、requestAnimationFrame 邊緣自動捲動；卡片視窗依原卡片座標進行縮放進出，並使用原生 dialog 處理模態焦點與 Escape。

開發環境有 Node.js 時，可在此資料夾執行：

```text
node verify.cjs
```

驗證涵蓋完整狀態重新載入、編輯寫入、子任務狀態、跨列表與同列排序、列表順序、備份還原、損壞回復、配額／權限錯誤、多視窗衝突、輸入轉義等。測試以最小 DOM 介面與記憶體儲存執行應用程式邏輯，**不代表已驗證真實瀏覽器的版面、觸控拖拽、動畫或 file:// 儲存行為**。

隔離 Chromium 介面測試已涵蓋便簽、時間工具、刪除確認與桌面／手機版面；真實重新開機與斷電復原未測試。
